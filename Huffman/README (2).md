Huffman Coding

Программа реализует алгоритм кодирования и декодирования файлов методом Хаффмана на языке Java.

Поддерживается работа как с текстовыми, так и с бинарными файлами.

Сборка



Для компиляции проекта выполните команду:

javac \*.java





Использование



Кодирование

java Main encode input.txt archive.huff



Декодирование

java Main decode archive.huff output.txt



Структура закодированного файла

Файл состоит из трех частей:



1\. Таблица частот символов



\* 256 целых чисел типа int

\* Размер: 1024 байта



2\. Количество значащих бит закодированного сообщения



\* Тип: int

\* Размер: 4 байта



3\. Закодированные данные



\* Битовая последовательность, полученная методом Хаффмана
